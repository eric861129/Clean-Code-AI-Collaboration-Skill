# Review Output Contract

Use this contract on the Full Path. Return every heading below and link decisions with stable identifiers:

- `F1`: repository fact plus revision, path and line, command, or other source.
- `A1`: assumption, its decision impact, and how to validate it.
- `U1`: unknown, criticality, responsible Owner, and next action.
- `O1`: option, cost, risk, fit conditions, and rejection reason.
- `E1`: command or artifact, environment, exit code, result, and limitation.

Use `None — Sources checked: ...` only after checking named sources. Distinguish that from `Not investigated`.
